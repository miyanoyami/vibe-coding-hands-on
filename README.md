## 基本設定

#### リポジトリの初期化

リポジトリとは git でプログラムを保存するフォルダの単位です。

「プロジェクト」などの言葉もほぼ同じ単位を指します。

「このフォルダ内を履歴管理する」という設定、と考えてください。

```
このプロジェクトではVibeCodingの練習のためにローカルのブラウザで動作する簡易的なDAWを開発します。
リポジトリを初期化して CLAUDE.md をコミットしてください。
```

#### CLAUDE.md の設定

CLAUDE.md とは ClaudeCode の基本的な設定ファイルです。

リポジトリ単位で ClaudeCode が守るべきルールや作業の方法を覚えさせておきます。

```
セキュリティやコンプライアンス上のリスクが生じないよう、最低限のルールをあらかじめ定めます。
- 外部のライブラリや素材を利用する場合は利用規約・ライセンス違反が生じない事を確認する。
- 十分に利用実績のあるものを利用する(最低50star, 推奨は100star以上)
- サプライチェーン攻撃対策として、リリース後14日以内のものは利用しない。
  - ただしゼロデイ攻撃対策で最新版を使うべきときはこの限りではない。
  
デザイン、ライティングに関しては過度のAI臭さが生じないように配慮します。
- 日本語のライティングにおいては yomiyasu を利用すること。
- 一般的な利用者の語彙にない言葉を用いないこと。
- デザインにおいては過剰なグラデーション、グラスモーフィズムの利用を避けること。
- 定番のCSSフレームワークやコンポーネントがあれば利用を検討すること。

メンテナンス性のため、適切なライブラリの利用と独自実装のバランスに配慮します。
- 複雑なアルゴリズムやコンポーネントの独自実装は避けること。
- 軽微な実装で済むもののために大きなライブラリの導入、多数のツールの導入を避けること。

また、その他確実に設定すべき事項があれば提案してください。
```

## 開発の開始

```
ブラウザで動作する最低限のDAWを実装したいと考えています。
現時点では以下の機能を持つこととします。
- ローカルの音源ファイルを選択する機能
- 音量を変更する機能
- 再生/一時停止機能
- ファイル書き出し機能

言語や必要なライブラリを検討してください。
```
